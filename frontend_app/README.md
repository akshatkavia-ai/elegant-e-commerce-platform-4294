# Electric Orange E-commerce Frontend

A bold, high-contrast React storefront following the "Electric Orange" style guide.

Quick start:
- npm install
- cp .env.example .env and set REACT_APP_API_BASE_URL, REACT_APP_STRIPE_PUBLISHABLE_KEY, REACT_APP_SITE_URL
- npm start

Features:
- Catalog grid, product detail, cart sidebar/page, checkout with address and Stripe Checkout, order success page.
- API wrappers in src/api with graceful mock fallback.
- Theme in src/theme.css.

See README-FEATURES.md for details.
